O que aprendi

  • git config --global user.name "Seu Nome" - Configura o nome do usuário globalmente no Git.
  • git config --global user.email "seuemail@exemplo.com" - Configura o e-mail do usuário globalmente.
  • git init - Inicializa um novo repositório Git local na pasta atual.
  • git status - Exibe o estado atual do diretório de trabalho e da área de stage.
  • git add . - Adiciona todos os arquivos modificados e novos à área de stage.
  • git diff - Mostra as alterações feitas nos arquivos que ainda não foram adicionadas ao stage.
  • git commit -m "Mensagem explicativa" - Grava as alterações que estão na área de stage no histórico do repositório.
  • git branch - Lista todas as branches locais do repositório.
  • git checkout -b nome-da-branch - Cria uma nova branch e alterna automaticamente para ela.
  • git merge nome-da-branch - Une o histórico da branch especificada à branch atual.
  • git remote add origin URL_DO_REPOSITORIO - Vincula o repositório local a um repositório remoto no GitHub.
  • git push -u origin main - Envia os commits locais para o repositório remoto pela primeira vez, definindo a branch padrão.
  • git clone URL_DO_REPOSITORIO - Baixa uma cópia completa de um repositório remoto existente para o computador.
  • git pull - Atualiza o repositório local buscando e mesclando as alterações do repositório remoto.
  • .gitignore - Arquivo de texto criado na raiz para listar arquivos e pastas que o Git deve ignorar permanentemente.
